# Text Translator

A React app that translates text into multiple languages using the Google Translate API via RapidAPI.

🔗 **Live Demo:** https://text-translator-sigma.vercel.app/

## Features

- Translate typed English text into Hindi, Spanish, French, German, Japanese, or Chinese
- Loading and error states while the request is in flight
- Clean, dark-themed UI

## Built With

- React
- Vite
- Tailwind CSS
- Google Translate API (via RapidAPI)
- lucide-react (icons)

## Environment Variables

This project needs a RapidAPI key to work. Create a `.env` file in the root:

```
VITE_RAPIDAPI_KEY=your_rapidapi_key_here
```

## Run Locally

```bash
git clone https://github.com/alok5824/text-translator.git
cd text-translator
npm install
# add your .env file as shown above
npm run dev
```
